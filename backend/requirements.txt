# Manual redaction. MuPDF is what actually deletes the covered text from a
# PDF's content stream, rather than drawing a box over it, and it renders the
# page images the selection UI draws on. Imported lazily in app/redaction.py,
# so an install without it still starts -- only the redaction endpoints fail,
# with a message saying to install this.
#
# NOTE: PyMuPDF is AGPL-3.0 (a commercial licence is sold separately). Fine
# for in-house use; revisit before shipping the PMS to anyone outside.
pymupdf==1.28.2

# OCR for scanned PDFs and JPG/PNG images needs nothing installed beyond this
# line. PyMuPDF's wheels carry Tesseract and Leptonica linked into MuPDF's own
# shared library, so OCR runs inside the API process: there is no Tesseract
# executable to install, nothing has to be on PATH, and no global
# TESSDATA_PREFIX is set.
#
# The one thing OCR needs from outside the process is the language data, and
# the project ships its own copy in backend/ocr/tessdata/. That is what makes
# this deployable to a shared server with no root access and no effect on
# anything else running there. See SETUP.md 3f.

# Transitive dependencies, pinned only so a rebuilt venv matches the one the
